# TechZone - Tienda de Tecnología

## Descripción
TechZone es una página web demostrativa de una tienda de tecnología. Presenta productos, navegación por secciones y recursos multimedia.

## Tecnologías utilizadas
- HTML5 para la estructura semántica.
- CSS3 para el diseño, las animaciones y las transiciones.
- Consultas media para adaptar la página a diferentes pantallas.
- Elementos multimedia HTML5 e integración de YouTube mediante iframe.
- Metaetiquetas SEO básicas.

## Archivos del proyecto
- `index.html`: estructura de la página.
- `css/style.css`: hoja de estilos.
- `media/audio.mp3`: archivo de audio local.
